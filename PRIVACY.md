# Mindspace Privacy Policy

Last updated: September 29, 2026

Mindspace: Infinite Canvas is designed to work locally and privately.

## Data collection

Mindspace does not collect, transmit, sell, or share personal information, analytics, advertising identifiers, board content, clipboard content, font information, or usage telemetry.

## Local storage

Board elements, drawings, notes, settings, and the canvas position are stored locally in the browser profile using IndexedDB. Data remains on the device unless the user explicitly exports a JSON backup or copies content to another application.

## Clipboard access

Clipboard permissions support user-initiated paste and copy actions. Mindspace does not monitor the clipboard in the background. Clipboard data is processed only when the user pastes into the page or chooses an explicit clipboard command.

## Local fonts

If supported by the browser, Mindspace can ask for permission to list locally installed fonts. This occurs only after a user action or when an existing browser permission is already granted. Font information stays in the local browser profile and is not transmitted.

## Network access

Mindspace requests no host permissions and has no application server. Link favicons are obtained through the browser's built-in favicon facility.

## Backups

Exported backups are created locally and saved through the browser's download mechanism. The user controls where these files are stored and whether they are shared.

## Changes

Material privacy changes will be documented in the repository changelog and reflected in this policy.

## Contact

Questions can be opened as an issue at <https://github.com/DopaLab/mindspace-infinite-canvas/issues>.
